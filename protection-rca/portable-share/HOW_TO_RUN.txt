Protection RCA — portable package
==================================

REQUIREMENTS ON THIS PC
  - Windows 10/11 64-bit
  - No Python / Node install needed (Python runtime is inside backend\.venv)

START ON YOUR LAPTOP
  1. Unzip / copy this whole folder anywhere (keep structure).
  2. Double-click ProtectionRCA.exe
  3. Browser opens http://127.0.0.1:8001/
  4. Keep the small "Protection RCA is running" window open.

SHARE ON YOUR NETWORK (others open your laptop)
  1. Start ProtectionRCA.exe on the host laptop.
  2. Note the LAN URL shown in the control window, e.g.
       http://192.168.1.50:8001/
  3. On first run, allow Windows Firewall for private networks.
  4. Other PCs on the SAME Wi-Fi / LAN open that LAN URL in Chrome/Edge.
  5. Do NOT use 127.0.0.1 from other PCs — that only works on the host.

STOP
  Close the Protection RCA control window (Stop & Close).
