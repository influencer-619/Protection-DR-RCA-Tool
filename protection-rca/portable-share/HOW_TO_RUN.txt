Protection RCA — portable package (ALL LATEST CODES)
======================================================

Packaged from current backend .py, rules, frontend\dist,
and ProtectionRCA.exe. Uses the bundled backend\.venv
(no Visual Studio / pip upgrade required on this PC).

START
  1. Copy this whole folder anywhere.
  2. Double-click ProtectionRCA.exe
  3. Browser opens http://127.0.0.1:8001/
  4. Keep the control window open while using the app.

LAN SHARE
  Use the LAN URL shown in the control window on other PCs
  on the same network (not 127.0.0.1 from other machines).

STOP
  Close the Protection RCA control window.
